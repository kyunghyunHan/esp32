# 부품 배선 메모

기존 ESP32 실습에서 기록한 연결이다. 보드 핀맵은 [ESP32](../boards/esp32.md)를 참고한다.

## OLED / SSD1306

| OLED 핀 | ESP32 핀 |
|---|---|
| SDA | GPIO21 |
| SCL | GPIO22 |

## PIR 센서

| 센서 핀 | 연결 |
|---|---|
| GND | GND |
| 3V3 | 3.3V |

신호 핀 연결은 아직 기록하지 않았다.

## 가변저항 (Potentiometer)

| 기존 메모의 단자 위치 | 연결 |
|---|---|
| 오른쪽 | 3.3V |
| 왼쪽 | GND |
| 가운데 | D34 |
